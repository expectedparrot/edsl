# EDSL Prolific integration

EDSL links Prolific studies to humanized surveys. The CLI supports filter discovery, cost estimates, account settings, draft creation, read-only preflight, publication, and response export through `ep humanize prolific`. The `Coop` API also supports updating and managing study state.

Use `ep humanize prolific --help` and the [API and CLI reference](references/api-and-cli.md) for supported operations, input fields, response objects, and constraints. This bundle covers EDSL integration behavior; recruitment design, sample-size and payment decisions, and Prolific study operations policy remain in EP Agent.

Related bundle: `edsl:edsl-human-survey`.
