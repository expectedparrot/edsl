# EDSL human survey notifications

EDSL exposes notification functionality for deployed human surveys, including immediate deliveries, scheduled deliveries, event callbacks, respondent filters, templates, and delivery status. Use `ep humanize deliveries`, `schedules`, and `callbacks` commands or the corresponding EDSL notification APIs. Run `ep humanize --help` to discover installed options.

See the [detailed notification guide](references/detailed-guide.md) for configuration and status fields. This skill describes EDSL integration mechanics; recruitment design and messaging strategy are EP Agent research workflows.
