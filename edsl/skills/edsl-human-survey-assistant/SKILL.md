# EDSL human survey assistant

EDSL can attach an AI chat assistant to a humanized survey, configure which questions it can assist with, and retrieve assistant interaction data. Use the humanize assistant CLI commands and schema fields documented by the installed version; see [configuration](references/config.md) and [data](references/data.md).

The assistant is separate from agent participation access (`edsl:edsl-human-survey-agent-access`).
