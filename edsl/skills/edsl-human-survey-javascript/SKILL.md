# EDSL human survey JavaScript

EDSL humanized survey questions can include browser-side scripts for interactive behavior and event logging. Use the documented question script fields and hooks; scripts can record events with `ep.log`. Check the [detailed JavaScript guide](references/detailed-guide.md) and [event reference](references/events.md), then use installed `ep humanize` help for configuration and retrieval commands.

This bundle documents EDSL's integration surface. Browser code must follow the documented sandbox and event contracts.
