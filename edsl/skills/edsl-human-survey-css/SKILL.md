# EDSL human survey CSS

Custom CSS for a humanized survey is stored in `humanize_schema['survey']['custom_css']`. EDSL exposes `edsl-*` classes for survey and question elements. Use the documented question-specific classes and verify selectors against the rendered survey.

`SurveyCSS` provides a programmatic interface. For a deployed survey, use the supported `ep humanize css` commands. See the [detailed CSS guide](references/detailed-guide.md) for class names, banner/logo selectors, progress steps, file upload controls, and example rules.
