---
title: "Contributing"
description: "Report problems, suggest features, and share EDSL code or examples."
---

EDSL is open source. We welcome bug reports, feature suggestions, and useful code or research examples through the [GitHub repository](https://github.com/expectedparrot/edsl).

## Report a problem

Open an issue with your EDSL version, a small example that reproduces the problem, what you expected, and what happened. `ep info` provides environment diagnostics with credentials redacted. Remove private study data and credentials from anything you share.

## Suggest a feature or share an example

Describe what you want to accomplish and how the feature or example would help. You can open an issue to discuss an idea or a pull request with proposed code. Include a short explanation of how to use it.

For questions or help with a study, email [info@expectedparrot.com](mailto:info@expectedparrot.com).
