**Expected Parrot Domain-Specific Language (EDSL)** is an open-source Python package for designing and running research with language models and AI agents.

EDSL provides structured objects for questions, surveys, agents, scenarios, models, and results. Researchers can use these to run experiments across multiple models and conditions, simulate survey responses, perform content analysis, and conduct other computational research tasks.

EDSL is developed by [Expected Parrot](https://www.expectedparrot.com/) and available under the [MIT License](https://github.com/expectedparrot/edsl/blob/main/LICENSE).

## How EDSL works with Expected Parrot

EDSL is also the foundation of the Expected Parrot platform. The [Research Agent](/en/latest/research_agent) uses EDSL to construct and execute studies and makes the generated code available for inspection and reuse. The [Builder](/en/latest/survey_builder) provides a visual interface for creating and editing studies using the same underlying structures.

You can work directly with EDSL in Python, including modifying studies created through the Research Agent or Builder. This lets you move between conversational, visual, and programmatic workflows without starting over.

EDSL can also be used independently with your own model access. See [Managing Keys](/en/latest/api_keys) for provider credentials and [local OpenAI-compatible models](/en/latest/local_openai_compatible) for local model setup.

## Why EDSL?

Researchers need to know how results were produced, especially when working with language models. EDSL makes it possible to explicitly specify and inspect questions, prompts, model selections, agent traits, scenarios, and other elements of a study. You can vary these systematically, compare outputs, and investigate sensitivity to your assumptions and methods.

EDSL handles model API calls, parallel execution, survey logic, and result organization. You can work with multiple models without building separate integrations for each provider. Its open-source implementation lets you inspect, modify, and extend the code that runs your study.

Expected Parrot provides additional infrastructure for [remote execution](/en/latest/remote_inference), [caching](/en/latest/remote_caching), [storage and sharing](/en/latest/coop). With remote caching enabled, matching model calls can reuse stored responses instead of generating new ones. Access requires an Expected Parrot account; see the caching guide for settings and details.

## Core concepts

| Object | Purpose |
| --- | --- |
| [Questions](/en/latest/questions) | Define what is asked and the response format, including free text, multiple choice, numerical, and matrix questions. |
| [Surveys](/en/latest/surveys) | Combine questions and define their order, conditional logic, and dependencies. |
| [Agents](/en/latest/agents) | Specify AI respondents with relevant traits, backgrounds, or instructions. |
| [Scenarios](/en/latest/scenarios) | Supply contexts, treatments, or data to parameterized questions. |
| [Models](/en/latest/language_models) | Choose the language models used to generate responses, including models from different providers. |
| [Results](/en/latest/results) | Store responses with associated questions, models, agents, scenarios, and information for analysis. |

Combine these objects to administer the same survey across agent profiles, models, experimental conditions, and datasets. For example, you can vary the wording of a message with scenarios, specify respondent profiles with agents, and compare responses across models. The [Starter Tutorial](/en/latest/starter_tutorial) shows how to construct and run these objects.

## Research with humans and AI

EDSL supports research using AI-generated responses as well as studies involving human respondents through Expected Parrot. Use simulations to investigate hypotheses, pretest instruments, explore experimental conditions, and evaluate model behavior. Use [Humanize](/en/latest/humanize) to field surveys with human participants, or the [Research Agent and Builder](/en/latest/research_agent) to design human surveys and AI-led interviews.

Human research can stand on its own. When comparing human and simulated responses, examine where model-generated results are useful and where they diverge from human evidence. AI simulations do not automatically represent the attitudes or behaviors of real populations and should not be treated as missing human observations.

## Working with results

EDSL provides methods for filtering, transforming, comparing, and analyzing [Results](/en/latest/results). Export data for use with other Python libraries and analysis tools, while retaining the study settings needed to interpret the responses.

Expected Parrot can also store study objects and results, cache model calls, and make research materials available to collaborators. See [File Store](/en/latest/filestore) and [Notebooks](/en/latest/notebooks) for sharing supporting materials.

## Getting started

To work with EDSL directly, install the package:

```bash
pip install edsl
```

Follow [EDSL Getting Started](/en/latest/getting_started) to configure model access, then use the [Starter Tutorial](/en/latest/starter_tutorial) to construct surveys, run them with models and agents, and analyze results.

You can also create and run studies through the [Research Agent](/en/latest/research_agent) or [Builder](/en/latest/survey_builder) without writing Python code.
