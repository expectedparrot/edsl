---
title: "Sharing a Colab notebook"
description: "Save a Colab notebook as supporting material for a study."
---

First use [Colab setup](/en/latest/colab_setup) to install EDSL and configure any required credentials. Sharing a notebook is separate from saving the survey, job, and completed results; preserve those objects with [Saving objects](/en/latest/guides/saving_objects).

## Download and inspect the notebook

In Colab, download the notebook as an `.ipynb` file. Review its code, cell outputs, and embedded data before sharing. Remove credentials and any private data that should not be included.

From an environment with EDSL and that file available:

```python
from edsl import Notebook

notebook = Notebook(path="study.ipynb")
```

Replace `study.ipynb` with the downloaded file's path. This reads the notebook locally; it does not execute its cells.

## Upload supporting material

With Expected Parrot authentication configured:

```python
info = notebook.push(
    description="Notebook accompanying the study",
    visibility="private",
)
```

This uploads the notebook. Retain the returned identifier and configure sharing deliberately. See [Notebooks and scripts](/en/latest/notebooks) for updating, downloading, and sharing notebook objects.
