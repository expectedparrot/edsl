[Google Colab](https://colab.research.google.com) runs Python notebooks in a hosted environment. In a new notebook, install EDSL in a code cell:

```text
%pip install edsl
```

Then follow the [Run your first survey](/en/latest/starter_tutorial) tutorial. Its local test model needs no credentials. Re-run installation when you start a new runtime.

## Log in to Expected Parrot

To use Expected Parrot's model access, run this in a cell:

```python
from edsl import login

login()
```

Follow the sign-in link in the output. EDSL retrieves your API key and configures the notebook session automatically. Run `login()` again when you start a new runtime. See [Notebook login](/en/latest/api_keys#log-in-from-a-notebook) for options.

## Use Colab secrets as an alternative

If you already have an Expected Parrot API key, you can instead add `EXPECTED_PARROT_API_KEY` to Colab's Secrets panel and enable access for this notebook. Load it without displaying the value:

```python
import os
from google.colab import userdata

os.environ["EXPECTED_PARROT_API_KEY"] = userdata.get("EXPECTED_PARROT_API_KEY")
```

For direct provider access, store and load the provider's environment variable instead. See [Model access](/en/latest/api_keys) to choose the execution path. Do not paste keys into notebook cells or saved output.

## Preserve your work

The runtime's local files can disappear when the session ends. Save study packages and results to durable storage or download them before closing the runtime. [Sharing a Colab notebook](/en/latest/colab_notebooks) explains how to save the notebook itself as supporting material.
