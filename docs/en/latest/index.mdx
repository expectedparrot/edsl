Expected Parrot Domain-Specific Language (EDSL) is an open-source Python package for conducting research with AI agents, language models, and human participants.

Use EDSL to run surveys and experiments, simulate responses, label data, and compare model outputs. You can then field surveys with human participants to validate findings and compare human and simulated responses.

Expected Parrot is a platform that lets you access language models, run studies remotely, reuse cached responses, and store and share research materials.

## Getting started with EDSL

To use EDSL in Python, install the package:

```bash
pip install edsl
```

Follow [Getting Started](/en/latest/getting_started) to configure EDSL, then work through the [Starter Tutorial](/en/latest/starter_tutorial) to construct a survey, run it, and analyze responses.

- [EDSL Overview](/en/latest/overview) — Understand the main components and workflow.
- [Human surveys](/en/latest/humanize) — Publish a survey and collect responses from participants.
- [Language models](/en/latest/language_models) — Find and configure models for your study.
- [Results](/en/latest/results) — Analyze and export your data.

For command-line workflows and coding-agent automation, see the [EDSL CLI Guide](/en/latest/cli).

For help designing, running, and analyzing studies through conversation, use the [Research Agent](https://www.expectedparrot.com/research-agent). Start with a research question, existing survey, or dataset and describe what you want to accomplish. The Research Agent uses EDSL to carry out research tasks and provides code you can inspect and modify.
