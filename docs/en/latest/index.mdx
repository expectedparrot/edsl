**Expected Parrot Domain-Specific Language (EDSL)** is an open-source Python package for designing, running, and analyzing research with humans and AI.

Define questions and surveys in code, collect responses from human participants, and analyze the data. You can also run experiments with language models, simulate survey responses, label data, and compare model outputs.

EDSL integrates with Expected Parrot to run studies remotely, cache model responses, and store and share research materials. Expected Parrot's [Research Agent](/en/latest/research_agent) uses EDSL to create and run studies, with code available for you to inspect and modify.

## Getting started

Install EDSL:

```bash
pip install edsl
```

Follow [EDSL Getting Started](/en/latest/getting_started) to configure model access, using an Expected Parrot account or your own model provider credentials. Then work through the [Starter Tutorial](/en/latest/starter_tutorial) to create a survey, run it, and inspect the results.

## Research with humans and AI

Collect survey responses from human participants, run simulations with AI respondents, or design studies that compare both. Human research can be the starting point and purpose of a study.

Use simulations to explore hypotheses, pretest instruments, and examine model behavior. AI-generated responses do not automatically represent real populations; compare them with human evidence when evaluating what they can tell you.

## Academic research and teaching

We support academic researchers, instructors, and students using Expected Parrot for research and coursework. Academic users can access the platform and receive an initial allocation of usage credits. Sign up with your academic email and [contact us](mailto:info@expectedparrot.com) for support.

See [Research with Expected Parrot](/en/latest/papers), the [Teaching guide](/en/latest/teaching), and [how to cite EDSL](/en/latest/citation).
