Expected Parrot uses usage credits for hosted services. Direct calls made with a model provider's own API key are billed by that provider. Constructing EDSL objects and running the local test model do not require usage credits.

## Check your account

With Expected Parrot authentication configured:

```python
from edsl import Coop

coop = Coop()
coop.get_balance()
```

`get_balance()` returns account balance information. Use `coop.get_profile()` to inspect the authenticated account. The CLI alternatives are:

```bash
ep balance
ep credits
```

`ep balance` returns the account balance in a JSON response. `ep credits` opens or returns the credits page; inspect the response instead of assuming a browser opened. You can also visit [account credits](https://www.expectedparrot.com/home/credits).

Review current pricing and the estimated workload before submitting a job. The [Costs guide](/en/latest/costs) explains estimates, recorded costs, and cost ledgers. A balance check is not a reservation of funds or a limit on future spending.

## Low balance email

Expected Parrot emails you when your balance drops below a threshold you choose. It is on by default, with a threshold of $10. The email is sent when a charge takes your balance below the threshold, at most once a day; adding credits that bring the balance back above it lets the next drop send another. Changing the threshold, or turning the email on, while your balance is already below it does not send one. To check or change it:

```python
coop.get_low_balance_alert()
coop.update_low_balance_alert(threshold_usd=25)
coop.update_low_balance_alert(enabled=False)
```

The threshold is in US dollars, from $1 to $10,000 with at most two decimal places. Both methods return the setting, including `enabled`, `threshold_usd` and `threshold_credits`. The CLI equivalents are:

```bash
ep balance alert
ep balance alert --threshold 25
ep balance alert --off
```

`ep balance alert` with no options returns the current setting; `--on`, `--off` and `--threshold` change it. You can also change it under Notifications in [account settings](https://www.expectedparrot.com/home/settings?tab=notifications).
