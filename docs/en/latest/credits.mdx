Expected Parrot uses usage credits for hosted services. Direct calls made with a model provider's own API key are billed by that provider. Constructing EDSL objects and running the local test model do not require usage credits.

## Check your account

With Expected Parrot authentication configured:

```python
from edsl import Coop

coop = Coop()
coop.get_balance()
```

`get_balance()` returns account balance information. Use `coop.get_profile()` to inspect the authenticated account. The CLI alternatives are:

```bash
ep balance
ep credits
```

`ep balance` returns the account balance in a JSON response. `ep credits` opens or returns the credits page; inspect the response instead of assuming a browser opened. You can also visit [account credits](https://www.expectedparrot.com/home/credits).

Review current pricing and the estimated workload before submitting a job. The [Costs guide](/en/latest/costs) explains estimates, recorded costs, and cost ledgers. A balance check is not a reservation of funds or a limit on future spending.
