---
title: "Installation"
description: "Install EDSL in a Python environment and verify the installation."
---

EDSL requires Python 3.10–3.13. The steps below install it on your computer so you can work in a Python notebook or script. If you prefer a browser-based notebook without local setup, use [Google Colab](/en/latest/colab_setup).

Run the following commands in a terminal. A virtual environment keeps the project's Python packages separate from those used by other projects.

## Create an environment

```bash
python3 -m venv .venv
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

## Install and verify

```bash
python -m pip install edsl
ep info
```

`ep info` reports the installed version and configuration, with credentials redacted. If `ep` is unavailable, use `python -m edsl info` in the same environment.

You can now construct EDSL objects and use the test model. Continue to the [Run your first survey](/en/latest/starter_tutorial) tutorial or [CLI Guide](/en/latest/cli). [Model access](/en/latest/api_keys) is needed for real model calls; installation itself does not require an Expected Parrot account.

## Upgrade EDSL

Upgrade an existing installation with:

```bash
python -m pip install --upgrade edsl
```
