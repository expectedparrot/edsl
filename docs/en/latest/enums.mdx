---
title: "Discovering types and services"
description: "Inspect supported question types and inference services in the installed version."
---

Discover types from the installed package instead of maintaining a copied list. This is useful for tools that construct EDSL objects or validate generated inputs.

## Question types

```python
from edsl import Question

question_types = Question.list_question_types()
example = Question.example("multiple_choice")
parameters = example.to_dict()
```

These operations construct local objects and do not call models. To inspect a particular type's schema, use `ep schema show --question_type multiple_choice`. See [Questions](/en/latest/questions#question-type-details) for response formats and construction parameters.

## Inference services

```python
from edsl import Model

services = Model.services()
```

A registered service is not a guarantee that every model is currently available to your account. Use [Language Models](/en/latest/language_models) and [Provider configuration](/en/latest/guides/providers) for current model discovery and access.
