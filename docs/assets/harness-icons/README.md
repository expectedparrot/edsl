# Harness logo sources

These small marks identify the harnesses in the EDSL README. They are not
endorsement statements.

- `codex.svg`: OpenAI mark from [Simple Icons 15.15.0](https://github.com/simple-icons/simple-icons/blob/15.15.0/icons/openai.svg), used to identify Codex.
- `claude-code.svg`: Claude mark from [Simple Icons 15.15.0](https://github.com/simple-icons/simple-icons/blob/15.15.0/icons/claude.svg).
- `opencode.svg`: OpenCode favicon from [the OpenCode repository](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/favicon/favicon-v3.svg).
- `pi.svg`: Pi favicon from [pi.dev](https://pi.dev/favicon.svg).
- `antigravity.png`: Google Antigravity icon from [Google Developers](https://developers.google.com/static/focus/images/antigravity-icon_1440.png), resized to 64 pixels.
- `vercel-fx.svg`: Vercel mark from [Simple Icons 15.15.0](https://github.com/simple-icons/simple-icons/blob/15.15.0/icons/vercel.svg), used to identify fx.

Simple Icons assets are CC0. Other marks remain the property of their
respective owners.
