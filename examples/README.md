# Research examples

Version-matched EDSL API examples now live in [`edsl/examples/`](../edsl/examples/)
and are included with the package. This top-level directory holds complete
research demonstrations, local acceptance harnesses, and saved study data whose
reports or execution outputs are specific to the study. Start with each project
README or runbook before running anything; some projects make model calls.
Repository report builders live in [`scripts/`](../scripts/README.md).
