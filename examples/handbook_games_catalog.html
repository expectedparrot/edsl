Workflow
parallel contributions -> aggregate -> repeated feedback
DSL pressure
No major gap identified.

Threshold / provision-point public good

The public return occurs only if total contributions reach a stated threshold; variants rebate contributions when provision fails.

Workflow
parallel contributions -> threshold -> rebate/payoff
DSL pressure
Needs sum, threshold branching, and participant-wise rebates.

Commons dilemma

Members choose whether to conserve or exploit a shared resource; individual exploitation pays privately while imposing losses on the group.

Workflow
parallel binary choice -> congestion payoff
DSL pressure
Needs count_where and map_payoff.

Best-shot public-good game

Workflow

DSL pressure
Maximum exists; participant-specific payoff mapping does not.

Workflow
parallel effort -> minimum -> repeated payoff feedback
DSL pressure
Needs collection minimum plus per-participant arithmetic.

Workflow

DSL pressure
Median exists; personalized distances and payoff maps do not.

Workflow
price clock -> first acceptance -> settlement
DSL pressure

Second-price / Vickrey auction

Workflow
sealed bids -> top-two order statistics -> payment
DSL pressure
Needs nth-order statistics and deterministic tie-breaking.

Workflow
open bid loop -> exits -> last bidder
DSL pressure
Needs live event streams, active rosters, and race-safe closure.

DSL pressure
